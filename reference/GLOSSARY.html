Glossary

The vocabulary the syllabus expects you to know and use precisely. Grows as the year does.

Using these words correctly is not decoration — the course goal explicitly grades “precision in mathematical communication.” Saying “the equation” when you mean “the expression” costs you points with a careful grader.

The four things people mix up

Expression
A mathematical phrase with no equals sign. You can simplify or evaluate an expression, but you cannot solve it — there's nothing to solve for. Example: 3x + 7
Equation
Two expressions set equal to each other. An equation makes a claim, and solving it means finding the values that make the claim true. Example: 3x + 7 = 22
Inequality
Like an equation, but with <, >, ≤, or ≥ instead of =. The solution is usually a whole range of numbers, not one number. Example: 3x + 7 < 22
Function
A rule that assigns exactly one output to each input. The “exactly one” is the whole definition — that's what separates a function from a plain relation. Example: f(x) = 3x + 7

Parts of an expression

Variable
A letter standing in for a number you don't know yet (or one that can change). The x in 3x + 7
Coefficient
The number multiplying a variable. In 3x, the coefficient is 3. In −x, it's −1 — not nothing.
Constant
A term with no variable in it. Its value never changes. The 7 in 3x + 7
Term
A single piece of an expression, separated from the others by + or −. Carry the sign in front of a term with it. 5x − 2y + 9 has three terms: 5x, −2y, and 9
Like terms
Terms with exactly the same variable part, raised to the same power. Only like terms can be combined. 3x and 5x are like terms. 3x and 3x² are not. Neither are 3x and 3y.

Solving

Solution
A value for the variable that makes the equation a true statement. To check a solution, substitute it back into the original equation — not into a line you rewrote, in case you made an error rewriting it.
Solution set
All the solutions, collected together. An equation might have one solution, no solutions (empty set, written ∅ or { }), or infinitely many.
Inverse operation
The operation that undoes another: addition undoes subtraction, multiplication undoes division. Solving an equation is applying inverse operations until the variable is alone.
Isolate the variable
Get the variable by itself on one side, with a number alone on the other. That's the goal of every equation you solve this year.
Identity
An equation that is true for every value of the variable, because both sides are secretly the same expression. Solving one collapses to something like 5 = 5. The solution is all real numbers, or infinitely many solutions. 2(x + 3) = 2x + 6
Contradiction
An equation that is true for no value of the variable. Solving one collapses to something false, like 3 = 5. The answer is no solution. 2x + 1 = 2x + 4

Properties you'll be asked to name

Distributive property
a(b + c) = ab + ac. The multiplier hits every term inside the parentheses — including the signs. This is the single most common place to lose a point in Unit 1.
Commutative property
Order doesn't matter for addition and multiplication: a + b = b + a. It does not hold for subtraction or division — 5 − 3 ≠ 3 − 5.
Associative property
Grouping doesn't matter for addition and multiplication: (a + b) + c = a + (b + c).
Properties of equality
Whatever you do to one side of an equation, you must do to the other. This is the justification for every step you take when solving — and it's the thing to name when a problem says “justify your reasoning.”
