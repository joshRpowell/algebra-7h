Lesson 0004 · Unit 1 — Expressions and Equations

Solving for a Variable

Formulas with no numbers in them. The same moves you already know — the other letters just come along.

So far every equation had one letter in it. Now they all have letters — A = ½bh, d = rt, y = mx + b. These are called literal equations, and they look much harder than they are.

Nothing new happens here. You use exactly the same moves as always: do the same thing to both sides until the letter you want is alone. The other letters just come along for the ride — treat them as if they were numbers you haven't been told yet.

If you can solve 12 = 3x by dividing both sides by 3, you can solve A = bh for b by dividing both sides by h. It's the same step.

The trick that makes these easy

Stuck on a formula? Solve the number version first, then copy your own steps.

Solve A = bh for b? Pretend it's 12 = b · 4. You'd divide both sides by 4. So divide both sides by h: b = A/h. Done.

Whatever you did to the number, do to the letter. This works on every problem below.

Worked example 1 — one division
d = rtSolve for t. It's multiplied by r.
d/r = rt/rDivide both sides by r — the inverse of multiplying.
t = d/rThe r's cancel on the right. Write the answer with t on the left.
Worked example 2 — a fraction in the way
A = ½bhSolve for h. Clear the fraction first (same move as Lesson 0003).
2A = bhMultiply both sides by 2.
h = 2A/bDivide both sides by b.

Sanity check: a triangle with A = 12 and b = 6 should have h = 24/6 = 4. And ½(6)(4) = 12. ✓

Worked example 3 — two steps, order matters
P = 2l + 2wSolve for w.
P − 2l = 2wSubtract 2l first — undo addition before multiplication.
w = (P − 2l)/2Divide by 2. The parentheses are required: the whole numerator gets divided.

Also correct: w = P/2 − l — the same thing, just simplified further. Both earn full credit.

The one that costs marks: dropping parentheses

When you divide a sum by something, every part of the sum gets divided:

(P − 2l)/2  ✓    P − 2l/2 = P − l  ✗

The second one only divided part of the numerator. If you're ever unsure, plug in numbers: with P = 20, l = 4, the correct answer gives w = 6 and the wrong one gives 16. A rectangle with perimeter 20 can't have a side of 16.

Write it like the rubric is watching

  • Say which variable you're solving for before you start. One line: "Solve for h." It costs nothing and shows the grader you know what the goal is.
  • Every step needs both sides. These problems are pure properties-of-equality — that's the justification to name if asked.
  • Finish with the variable alone on the left: write h = 2A/b, not 2A/b = h. Same maths, but the first is the answer to the question that was asked.

Ask your tutor. If a problem still doesn't make sense after you read the solution, say so — you'll get it explained a different way. Stuck on an assigned problem? Don't paste it in; ask for a similar one with different numbers.
