Lesson 0001 · Unit 1 — Expressions and Equations

When x Is on Both Sides

One move handles every equation like this. Then one twist that decides who gets full marks on the checkpoint.

You can already solve 3x + 5 = 20. Every step you take there has the same purpose: get x alone. This lesson is the same job with one new obstacle — x shows up on both sides of the equals sign — and then one genuinely sneaky case that most of your class will get wrong the first time.

That sneaky case is why this is your first lesson. It's the classic Unit 1 checkpoint-killer: not hard, just unfamiliar, so strong students walk straight into it. Fifteen minutes now and it can't touch you.

The one move

Variables are terms, and terms can move. You already move numbers across the equals sign by doing the same thing to both sides. A variable term works exactly the same way. Subtract 3x from both sides and it vanishes from one side and appears on the other — no new rule required.

So: gather all the variable terms on one side and all the constants on the other. Then finish the way you always have.

Worked example 1
5x + 3 = 3x + 11Start. x on both sides.
5x + 3 − 3x = 3x + 11 − 3xSubtract 3x from both sides — properties of equality.
2x + 3 = 11Combine like terms. Now it's an equation you've solved a hundred times.
2x = 8Subtract 3 from both sides.
x = 4Divide both sides by 2.

Check: left side 5(4) + 3 = 23; right side 3(4) + 11 = 23. Both 23. ✓

Which side do you move the variable to?

Either works — you'll get the same answer. But there's a reason to prefer one: move the smaller variable term, so the coefficient you're left with is positive. In the example above, moving 3x left us with 2x. Moving 5x instead would have given −2x = −8 — same answer, two extra chances to drop a negative sign. Top students don't avoid sign errors by being careful. They avoid them by choosing the path with fewer signs.

Worked example 2 — with parentheses and a negative answer
4(x − 2) = 6x + 4Parentheses first.
4x − 8 = 6x + 4Distribute: the 4 hits both terms inside, sign included.
−8 = 2x + 4Subtract 4x from both sides (the smaller one).
−12 = 2xSubtract 4 from both sides.
x = −6Divide by 2. x on the right is fine — flip it for readability.

Check: 4(−6 − 2) = 4(−8) = −32; 6(−6) + 4 = −32. ✓

The twist: when x disappears

Sometimes you subtract the variable term from both sides and the variable vanishes from the equation entirely. Students panic here and write “x = 0”. That is wrong, and it is worth real points.

Nothing has gone wrong. The equation is just telling you something different than usual. Read the statement that's left and ask: is it true or false?

False → No solution 
  5x − 8 = 5x + 1
−5x        −5x
  −8 = 1   ← false!

−8 is never equal to 1, no matter what x is. So no number can make this equation true.

Answer: no solution (the empty set, ∅)

True → Infinitely many 
  4(2x − 1) = 8x − 4
   8x − 4 = 8x − 4
−8x         −8x
       −4 = −4  ← true!

Both sides were the same expression in disguise. Every number works.

Answer: infinitely many solutions (all real numbers)

The rule, in one line

A linear equation has exactly one solution, no solutions, or infinitely many solutions — never any other number of them. If the variable survives, you get one solution. If it cancels out, look at what's left: a false statement means no solution; a true statement means infinitely many. (Khan Academy covers this same rule here.)

The vocabulary, for when a problem asks you to name it: an equation that's always true is an identity; one that's never true is a contradiction. Both are in the glossary.

Write it like the rubric is watching

Your syllabus grades “precision in mathematical communication” and the ability to justify solutions — not just the final answer. On a checkpoint, that means:

  • One line per step, equals signs lined up, nothing done in your head.
  • When the variable cancels, don't just write the answer — write the sentence: “−8 = 1 is false, so there is no solution.” That one sentence is the difference between full credit and partial credit.
  • Check your answer in the original equation, not in a line you rewrote — otherwise you'll confirm your own mistake.
